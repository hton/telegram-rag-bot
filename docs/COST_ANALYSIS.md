# Анализ стоимости использования

## 📊 Обзор

Telegram RAG Bot использует OpenAI API для обработки запросов. Этот документ содержит детальный расчет стоимости одного ответа бота.

## 🤖 Используемые модели OpenAI

### Chat/Completion модели:
- **gpt-4o-mini** (параметр `LLM_MODEL` в `config/.env`)
  - Используется для: Query Expansion, Reranking, Answer Generation
  - Оптимальный баланс качества и стоимости

### Embedding модели:
- **text-embedding-ada-002** (параметр `EMBEDDING_MODEL` в `config/.env`)
  - Генерирует 1536-мерные векторы
  - Используется для векторного поиска

## 💰 Актуальные цены OpenAI (2025)

### gpt-4o-mini:
- **Input:** $0.15 / 1M токенов
- **Output:** $0.60 / 1M токенов

### text-embedding-ada-002:
- **Standard:** $0.10 / 1M токенов

**Курс валюты:** ~78 RUB за 1 USD (декабрь 2025)

## 🔄 RAG Pipeline - API вызовы на один запрос

Бот выполняет **3-4 вызова OpenAI API** на каждый запрос пользователя:

### ✅ Обязательные вызовы

#### 1. Embedding (векторизация запроса)
- **Токены:** ~20-50 (средний запрос)
- **Стоимость:**
  - USD: ~$0.000001-0.000005
  - RUB: ~₽0.00008-0.0004
- **Назначение:** Преобразование текста запроса в вектор для поиска

#### 2. Reranking (переранжирование результатов)
- **Модель:** gpt-4o-mini
- **Prompt tokens:** ~500-1500 (зависит от количества найденных документов)
- **Completion tokens:** ~50-200 (выбор топ-5 источников)
- **Стоимость:**
  - Input: (500-1500) × $0.15/1M = $0.000075-0.000225
  - Output: (50-200) × $0.60/1M = $0.000030-0.000120
  - **Итого USD:** $0.000105-0.000345
  - **Итого RUB:** ₽0.008-0.027
- **Назначение:** Выбор наиболее релевантных документов из найденных

#### 3. Answer Generation (генерация ответа)
- **Модель:** gpt-4o-mini
- **Prompt tokens:** ~1500-3500 (контекст + история диалога + вопрос)
- **Completion tokens:** ~100-1000 (длина ответа, max 1000)
- **Стоимость:**
  - Input: (1500-3500) × $0.15/1M = $0.000225-0.000525
  - Output: (100-1000) × $0.60/1M = $0.000060-0.000600
  - **Итого USD:** $0.000285-0.001125
  - **Итого RUB:** ₽0.022-0.088
- **Назначение:** Генерация финального ответа на основе контекста

### ⚙️ Опциональные вызовы

#### 4. Query Expansion (расширение запроса)
- **Условие:** Включается параметром `QUERY_EXPANSION_ENABLED=true`
- **Модель:** gpt-4o-mini
- **Prompt tokens:** ~150-300
- **Completion tokens:** ~50-150
- **Стоимость:**
  - Input: (150-300) × $0.15/1M = $0.000023-0.000045
  - Output: (50-150) × $0.60/1M = $0.000030-0.000090
  - **Итого USD:** $0.000053-0.000135
  - **Итого RUB:** ₽0.004-0.011
- **Назначение:** Расширение аббревиатур и технических терминов

## 📊 Факторы, влияющие на стоимость

### 1. Длина вопроса пользователя
- Влияет на: Embedding tokens, Generation prompt tokens
- Короткий вопрос (5-10 слов): минимальные токены
- Длинный вопрос (50+ слов): увеличение на 20-30%

### 2. Количество найденных документов
- Влияет на: Reranking prompt tokens
- `TOP_K_RESULTS=15` (по умолчанию)
- Больше документов → больше токенов для reranking

### 3. История диалога
- Влияет на: Generation prompt tokens
- `CONTEXT_WINDOW=3` (по умолчанию)
- Каждое сообщение в истории добавляет ~100-500 токенов

### 4. Длина ответа
- Влияет на: Generation completion tokens
- `MAX_TOKENS=1000` (по умолчанию)
- Completion tokens стоят в 4 раза дороже input tokens

### 5. Query Expansion
- Включение/выключение: `QUERY_EXPANSION_ENABLED`
- Добавляет дополнительный API вызов
- Увеличивает стоимость на ~$0.00005-0.00013

## 🎯 Рекомендации по оптимизации стоимости

### ✅ Уже реализовано

#### 1. Использование gpt-4o-mini
- **Экономия:** В ~30 раз дешевле GPT-4
- **Качество:** Сохраняется высокое качество ответов
- **Статус:** ✅ Реализовано по умолчанию

#### 2. Настройка MAX_TOKENS
- **Параметр:** `MAX_TOKENS=1000`
- **Эффект:** Ограничивает максимальную длину ответа
- **Статус:** ✅ Настроено оптимально

#### 3. Контроль контекста диалога
- **Параметр:** `CONTEXT_WINDOW=3`
- **Эффект:** Баланс между качеством и стоимостью
- **Статус:** ✅ Оптимальное значение

### ⚠️ Возможные улучшения

#### 1. Переход на text-embedding-3-small
- **Текущая модель:** text-embedding-ada-002 ($0.10/1M)
- **Альтернатива:** text-embedding-3-small ($0.02/1M)
- **Экономия:** 80% на embedding вызовах
- **Эффект:** ~$0.00004 экономии на запрос
- **Риски:** Требует тестирования качества поиска

#### 2. Отключение Query Expansion
- **Параметр:** `QUERY_EXPANSION_ENABLED=false`
- **Экономия:** ~$0.00005-0.00013 на запрос (~10%)
- **Риски:** Возможное снижение качества для аббревиатур

#### 3. Уменьшение TOP_K_RESULTS
- **Текущее:** `TOP_K_RESULTS=15`
- **Альтернатива:** `TOP_K_RESULTS=10`
- **Экономия:** ~15-20% на reranking
- **Риски:** Может пропустить релевантные документы

#### 4. Использование Batch API
- **Для:** Массовой обработки запросов (не в реальном времени)
- **Экономия:** 50% скидка на все вызовы
- **Применимость:** Подходит для фоновой обработки, не для чата

## 📉 Мониторинг затрат

### Prometheus метрики

Бот автоматически отслеживает использование токенов:

```promql
# Общее количество использованных токенов
openai_tokens_used_total{model="gpt-4o-mini", token_type="prompt"}
openai_tokens_used_total{model="gpt-4o-mini", token_type="completion"}
openai_tokens_used_total{model="text-embedding-ada-002", token_type="prompt"}

# Количество API вызовов
openai_api_calls_total{model="gpt-4o-mini", operation="reranking"}
openai_api_calls_total{model="gpt-4o-mini", operation="generation"}
```

### Расчет затрат по метрикам

```bash
# Экспортировать метрики
curl http://localhost:8000/metrics | grep openai_tokens_used_total

# Рассчитать стоимость
# prompt_tokens × $0.15 / 1,000,000 + completion_tokens × $0.60 / 1,000,000
```
